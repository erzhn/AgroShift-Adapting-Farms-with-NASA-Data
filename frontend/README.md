# AgroShift — интерфейс хозяйства

Next.js App Router, React, TypeScript, MapLibre и ECharts. Главная страница `/`:
карта и культуры, календарь сезона, профиль, создание/изменение полей,
справочники, переключение стратегии и сценария. Языки главного экрана — RU/KY/EN.
Экран `/strategies?farm=<uuid>` принадлежит модулю стратегий и денег.

## Запуск целиком

В корне репозитория (нужен Docker Desktop):

```sh
docker compose up --build -d
docker compose exec -T api python -m scripts.seed
```

Интерфейс: http://localhost:3000. API: http://localhost:8000/docs.
Seed повторяемый: существующие значения и изменения пользователя сохраняются.
Если порт занят, задайте `FRONTEND_PORT=3001` в корневом `.env`.
API и frontend имеют healthcheck; frontend ожидает готовности API и базы.

## Разработка

Нужен Node.js 24. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Запущенный API должен слушать порт 8000. Запросы браузера идут через `/api/v1`:
Next проксирует их к API, поэтому интерфейсу не нужен отдельный CORS-доступ.
Для другого адреса задайте `API_INTERNAL_URL` перед запуском/сборкой.
Docker использует `http://api:8000` во время сборки. Настройка rewrite входит в сборку.

```sh
npm run typecheck
npm test
npm run build
npm start
```

`package-lock.json` фиксирует зависимости; production-образ содержит standalone-сборку.
Статические карты OpenStreetMap требуют сети. При недоступной подложке остаются
контуры и список полей; если WebGL недоступен, поля можно выбрать в списке.

## Интеграция лент

`components/farms/PlanningLanes.tsx` экспортирует `LaneProps` и `FarmIntegrations`.
Лента получает `farm`, `year`, `month` (1–12), `strategyId`, `scenario`, `runId`,
`language` и `onMonthChange`. В клиентском компоненте можно передать
`<Dashboard integrations={{WaterLane}} />` с адаптером компонента воды.
`MoneyIntegration` уже подключает `components/strategies/MoneyLane.tsx`,
передавая конкретный `runId` выбранного хозяйства, а не старый прогон из хранилища.

Варианты пересчитываются после правки профиля/поля и смены сценария. Расчёт идёт
для последнего сезона, когда на каждом поле задана культура и известны деньги.
На будущие годы расчёты не переносятся автоматически. Выбор варианта меняет
предпросмотр культур и денежную ленту; сохранённые посевы не изменяются.
Недостающий `WaterLane` показан честным пустым состоянием.

Сценарий «как 2023» требует исторического снимка: текущий модуль стратегий принимает
множители условий, поэтому этот сценарий не подменяется средним годом. Другие
пресеты передают месяцы изменения воды, множитель корма и задержку оплаты отдельно.
Климатическая/водная заглушка и оценочная экономика явно отмечаются на экране.

Формы работают с реальным API. Пустые числовые поля означают неизвестное значение,
ноль сохраняется как ноль. PATCH отправляет только изменения. Поле можно добавить
точкой с площадью; изменение границ Polygon доступно через GeoJSON API.
