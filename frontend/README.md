# Frontend

Место под клиент (раздел 11.1 ТЗ): Next.js (React, TypeScript), MapLibre GL JS, ECharts, i18next, PWA.
Если не хватает фронтендера — Streamlit.

API: http://localhost:8000/api/v1, контракты — http://localhost:8000/docs (OpenAPI).
CORS для `http://localhost:3000` уже открыт (`CORS_ORIGINS` в `.env`).
